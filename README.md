
# Linear Regression – Machine Learning Project

## About the Project
This project explores Linear Regression using Python
and Machine Learning techniques.

The objective is to understand how Linear Regression
works and how it can be used to predict numerical values.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- NumPy

## Project Contents
- Data loading and exploration
- Data preprocessing
- Linear Regression model
- Model training and prediction
- Model evaluation

## Installation

Install the required libraries:

```bash
pip install -r requirements.txt
```

## How to Run
Open the Jupyter Notebook:

`Linear_Regression_Machine_Learning_Project.ipynb`

You can run it using Google Colab or Jupyter Notebook.
